# 使用

## 拍摄和叙述

1. 从入户开始，连续走到每个要讨论的房间。中途不要剪掉房间之间的那段。
2. 至少在一个房间里站住，面对窗户向外，说出房间名称，以及方向。可以说「向外是南」，也可以读罗盘方位角，0 为北，90 为东。
3. 经过门时说明从哪一间到哪一间。
4. 拍到或写明床、床头、沙发、书桌、餐桌、灶、水槽、镜子、马桶。没有看到的东西不要补。
5. 单独说明电梯：是否靠近；相对入户在哪里；挨着哪些房间或哪条公共走廊；电梯门朝哪；大约多少米；机房在上方、旁边还是不清楚；实际听到的声音和感到的振动。没注意过就写「未观察」。

只说「主卧朝南」，程序不会画出其他房间，也不会给它们标方向。

## 手绘

手绘是和视频并列的一条完整路径。点「从空白平面开始」，再打开「户型」。

房间名称包括男主人房、女主人房、儿童房、客房、客厅、餐厅、厨房、卫生间、书房和入户。厕所在构件一排，点下去就是一间卫生间。名称可以改，改完仍印在房间图形上，拖动或拉大时一起动。

门和窗画在墙上，长度就是宽度。拖动开口沿墙移动，拖动端点改变宽度。阳台贴着当前选中房间的某一侧，之后也可以拖动和改变大小。马桶用「添加马桶」放进厕所或卫生间。

格子仍是示意图，除非把比例改成已实测。

## 页面

1. **材料**：空白平面、示例、文字摘录、本机视频关键帧、JSON、video-to-3d 的 scene.json、照片底图。视频不是必经步骤。
2. **澄清**：列出还不能下结论的问题，并显示依据。
3. **户型**：在图上拖动、拉动圆点改变大小，也可以用数字作精确调整。勾选相对位置、整图的北，以及拓扑、朝向、家具三项确认。
4. **电梯**：填写套外的电梯。选择「否」之后，电梯规则标为不适用。
5. **评估**：确认三项之前只能看预览。最终文本仍然把文化解读和实用观察分开。
6. **导出**：JSON、SVG、PNG。打印对话框里可以选择存储为 PDF。

示例数据的标题和黄条都写着「不是真实住宅」。

## 比例

默认是示意图。格子上的米数只表示相对长短。只有在导入 video-to-3d 的完整矩形，或你自己把项目标成实测时，才按实测语气书写，并且仍会保留原来的警告。

## 进阶流派

八宅要你确认的是整宅坐山，不是某一扇窗。玄空飞星还要建造或入伙年份；即使有年份，没有二十四山度数也不起山星、向星盘。程序不会用今年代替建成年。
