# 隐私与安全

视频、照片和户型默认只在你的浏览器里。服务器不把上传写进磁盘，仓库也不保存用户的视频、平面或密钥。

发送关键帧之前必须勾选同意。同意文字里写着目的主机。清除按钮会撤销本机的对象 URL。刷新页面后，没有下载的内容不会留下。

服务器拒绝：

- 没有同意的请求
- 超过 4 张、单张过大，或文件头不是 JPEG、PNG、WEBP 的画面
- 不在 `AI_ALLOWED_HOSTS` 里的地址、非 https、带账号的地址
- 重定向
- 超过每小时次数的请求

导入的 JSON 会去掉尖括号、限制房间数量和字符串长度，并且把 `ai.analyzed` 设回否。这样一份别人传来的文件不能自称已经分析过视频。

请不要在旁白里念证件号、密码或别人的姓名住址。
