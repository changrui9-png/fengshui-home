# 局限

- 浏览器不能可靠地从视频文件里听写旁白。方向如果只说在声音里，需要你把文字贴上。第一版不另接语音识别，避免在没有这条能力时假装听懂了。
- 关键帧不是连续重建。没有配置模型时，帧只是给你自己看。
- video-to-3d 的结果通常是单间矩形，没有罗盘、门和家具。导入后仍要你补充朝向。
- 照片底图不会被描成墙线。
- 示意图上的长度不能用来判断「宅门大内小」，也不能代替实测。
- 八宅口诀按「后天八卦顺时针、从坐山下一位起读」计算，便于复核。中国哲学书电子化计划里的《阳宅十书》OCR 错字很多，所以报告不引用那段 OCR。
- 玄空的替卦、空亡和山向飞星不起盘。
- 电梯的通俗「门冲」没有古典条文。报告只在方位齐全时比较两个角度，并单独写噪声和隐私。
- 打印 PDF 依赖浏览器的打印功能，不是另一套排版引擎。
- 静态网页托管没有服务器，因此不能在那种托管上调用模型。见 [部署](部署.md)。
