# 架构

浏览器里是 Vite 和 React。评估、朝向、电梯和导入都是纯 TypeScript，测试直接调用这些函数。

平面图是一张 SVG。房间、门窗、家具、罗盘、套外的电梯和走廊都在这张图上。房间和家具可以在图上拖动，并用圆点改变大小；门和窗是墙上一段可见的开口，能沿墙移动、改变宽度。导出的 SVG 和页面里的图用同一段代码。手绘从空白平面开始，不依赖视频。

`server/index.ts` 在生产环境里提供静态文件和两个接口：

- `GET /api/health` 只说明有没有配置模型、提供方名字和主机名，不返回密钥
- `POST /api/analyze` 检查同意、图片文件头、大小和主机名单，再调用模型

模型输出先过一层筛选：依据必须能在旁白里逐字找到，或者在确实送了画面时以「画面」开头。尺寸字段被丢弃。

朝向模块区分两种平面：

- `shared-plan`：业主确认这些房间在同一张图上。此时一面墙的向外方位可以旋转整张图的罗盘解释，其他房间因此有墙向，但坐标不会被发明。
- `unlinked`：只有个别房间自己的朝向。其他房间保持未知。

规则每个结果都有编号、状态、为什么评或为什么不评、证据、来源链接。状态包括已评估、不适用、证据不足、暂不结论。
